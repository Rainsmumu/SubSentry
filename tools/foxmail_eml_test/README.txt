SubSentry Foxmail EML草稿兼容性测试
=================================

测试目的
--------
验证Foxmail能否将本地.eml邮件文件识别为可编辑的未发送草稿。

该方案完全绕开Simple MAPI，不使用SMTP，也不调用任何发送接口。
程序只生成本地邮件文件并请求Windows打开它。

测试步骤
--------
1. 确认Foxmail已经打开并正常登录。
2. 双击run_foxmail_eml_test.bat。
3. 阅读安全说明后输入Y。
4. 检查是否由Foxmail打开，以及邮件能否直接编辑。
5. 检查中文标题、正文、测试收件人和附件。
6. 请勿发送，关闭邮件窗口后回答六个Y/N问题。

安全说明
--------
- 测试收件人为test@example.invalid，不是真实邮箱。
- 程序不会读取Foxmail账号、密码或已有邮件。
- 程序不会修改注册表、Windows设置或SubSentry数据。
- 程序不会安装依赖，也不需要联网。
- 生成的.eml文件本身只是一个本地邮件文档。

结果
----
程序会生成“Foxmail_EML_测试结果.txt”。
请将结果文件或Foxmail打开后的截图发回。
