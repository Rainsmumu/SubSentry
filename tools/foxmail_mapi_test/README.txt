SubSentry Foxmail兼容性测试
============================

用途
----
测试值班机上的Foxmail能否被SubSentry调用，并打开一封带有中文标题、
中文正文、测试收件人和附件的邮件草稿。

本测试使用Python标准库和Windows自带的Simple MAPI接口，不联网、
不安装软件，也不需要额外下载Python依赖。

运行前
------
1. 确认Foxmail已经登录值班邮箱并能正常使用。
2. 在Windows“默认应用”中，将Foxmail设为默认电子邮件应用。
3. 保持Foxmail处于打开状态。

测试步骤
--------
1. 双击 run_foxmail_mapi_test.bat。
2. 阅读提示后输入 Y 并按回车。
3. 如果Foxmail打开写信窗口，请勿点击发送。
4. 检查标题、正文、收件人和附件，随后直接关闭草稿。
5. 回到黑色窗口，根据实际情况回答五个Y/N问题。

安全说明
--------
- 测试收件人为 test@example.invalid，不是真实邮箱。
- 程序强制要求显示写信窗口，不会后台静默发送。
- 程序不会读取或保存Foxmail账号、密码和邮件内容。
- 测试不会修改SubSentry的槽路表和故障记录。

结果
----
程序会在当前文件夹生成“Foxmail_MAPI_测试结果.txt”。
请将这个结果文件或窗口截图发回，用于决定是否正式接入SubSentry。

常见现象
--------
- 打开了其他邮件软件：Foxmail还不是Windows默认电子邮件应用。
- 返回码27：Foxmail的Simple MAPI接口不支持Unicode，需要改用兼容方案。
- 没有打开窗口或返回码2/3：可能是默认客户端注册、登录状态或
  32/64位MAPI兼容问题，请保留结果文件，不要反复安装或卸载软件。
