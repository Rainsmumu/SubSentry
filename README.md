# SubSentry — 海缆故障传报系统

上海国际局海缆故障通报辅助工具，支持崇明/南汇两个登陆站出口 8 条海缆段落的故障通报自动生成。

---

## 功能概览

| 功能 | 说明 |
|------|------|
| **实时态势图** | SVG 可视化展示 8 条海缆段落状态（正常 / 中断），悬停显示详情 |
| **首报生成** | 自动填充首报邮件、首报短信，一键复制 |
| **续报生成** | 自动填充续报邮件、续报微信，一键复制 |
| **业务影响统计** | 从金桥机房电路表实时分析受影响电路（IP/IEPL/IPLC/DDN），区分无保护/主用/备用/主备双断 |
| **Excel 下载** | 生成《国际海缆故障影响业务统计表》xlsx 附件，对齐历史样例格式 |
| **主备双断检测** | 多条海缆同时故障时，动态识别累积主备双断电路 |
| **故障时间线** | 记录所有故障事件，支持手动解除，自动持久化重启恢复 |

## 安装与启动

### 1. 放置数据文件

将金桥机房电路表 Excel 文件命名为以下名称，放到项目根目录：


> 该文件每次生成通报时**实时读取**（有缓存，文件更新后会自动刷新）。

```bash
cd SubSentry
python app.py
```

## 使用说明

### 录入故障

1. 在左侧「故障录入」区域，从下拉菜单选择故障海缆段落
2. 选择中断时间（精确到分钟）
3. 点击「📡 生成通报」按钮

系统将：
- 自动更新左侧态势图（故障海缆变为红色虚线）
- 生成四段通报文本
- 计算业务影响统计

### 复制通报

右侧通报区域有四个 Tab：

| Tab | 用途 |
|-----|------|
| 首报·邮件 | 第一时间告知相关方 |
| 首报·短信 | C1+ 故障短信通报 |
| 续报·邮件 | 含附件的业务影响通报 |
| 续报·微信 | 微信通报（含 IP 损失和专线明细） |

点击「📋 复制」后直接粘贴到邮件客户端或微信。

### 下载附件

点击「📥 下载业务影响统计表 (.xlsx)」，生成可直接作为续报邮件附件的 Excel 文件。

文件名格式：`国际海缆故障影响业务统计表 {海缆名} {段落}（{路由}）.xlsx`

### 多条海缆故障

可连续录入多条海缆故障。系统会：
- 在态势图上同时标注所有中断段落
- 对新录入的故障进行全量重算，识别**主备双断**电路
- 在故障时间线中显示所有故障事件

### 解除故障

在左侧「故障时间线」中点击「解除」按钮，系统自动重算所有影响。

## 业务影响分类说明

| 标注 | 含义 | 业务是否中断 |
|------|------|------------|
| **无保护** | 单腿电路，路由已断 | ✅ 中断 |
| **主备双断** | 所有路由均已断 | ✅ 中断 |
| **主用** | 第一路由断，但备用存活 | ❌ 通过备用在跑 |
| **备用** | 第一路由存活，某备用断 | ❌ 保护能力降低 |
| **疑似** | 路由写法模糊（如"TPE崇明"无法区分段落），需人工确认 | ⚠️ 待确认 |

> 微信通报中的「X 条专线中断」只统计**无保护 + 主备双断**的电路。
> IP 带宽损失同样只统计真正中断的 IP 电路。

## 数据文件说明

| 文件 | 说明 |
|------|------|
| `金桥机房电路表.xlsx` | **用户维护**，每次生成通报时实时读取。更新后下次查询自动生效。<br>**新增列（可选）**：第29列"当前路由"，用于记录因故障调度后实际运行的海缆。 |
| `data/fault_state.json` | **系统自动维护**，存储当前故障事件。重启后自动恢复故障状态。 |

### 当前路由功能说明

当电路因多条海缆故障被调度到其他海缆时，可在金桥机房电路表第29列（"当前路由"）填写实际承载的海缆名称。

**使用场景：**
- 设计路由：APG S3（主）+ TPE S1S（备1）+ APCN2 S4A（备2）
- 三条全断后，人工调度到 NCP S1.1
- 在"当前路由"列填写：`NCP S1.1`
- 此时如果 NCP S1.1 断了，系统会正确识别该电路受影响

**系统行为：**
- 优先匹配"当前路由"，如果为空则匹配设计路由（第一/二/三路由）
- 运行在临时路由的电路会在统计表和微信通报中标注"⚠️临时路由"
- 临时路由断路时，直接标记为"无保护"（因为已无备用）

## 项目结构

```
SubSentry/
├── app.py                  # Flask 主程序
├── cable_config.py         # 8 条海缆段落硬编码配置
├── circuit_analyzer.py     # 电路分析引擎（匹配 / 分类 / 统计）
├── report_builder.py       # 四种通报模板填充
├── excel_builder.py        # 统计表 xlsx 生成
├── data/
│   └── fault_state.json    # 故障状态持久化（自动创建）
├── templates/
│   └── index.html          # 单页前端
├── 金桥机房电路表.xlsx       # 数据文件（用户放置）
└── README.md
```
