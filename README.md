# SubSentry — 海缆故障传报系统

上海国际局海缆故障通报辅助工具，支持崇明/南汇两个登陆站出口 8 条海缆段落的故障通报自动生成。

---

## 功能概览

| 功能 | 说明 |
|------|------|
| **实时态势图** | SVG 可视化展示 8 条海缆段落状态（正常 / 中断），悬停显示详情 |
| **全流程传报** | 崇明出口支持首报、业务影响、断点续报、维修计划续报和终报；南汇出口仅显示业务影响传报 |
| **渠道进度确认** | 各阶段按电话、邮件、短信、微信和专业主管文件分别确认，圆形时间线显示完成进度 |
| **变量复用** | 海缆段落自动确定登陆站、方向、NOC及责任人，断点、维修和修复信息只填写一次 |
| **业务影响统计** | 从金桥机房电路表实时分析受影响电路（IP/IEPL/IPLC/DDN），区分无保护/主用/备用/主备双断 |
| **Excel 下载** | 生成《国际海缆故障影响业务统计表》xlsx 附件，对齐历史样例格式 |
| **专业主管文件** | 崇明出口按阶段追加Excel列，新增或变化的内容标红，历史列保持不变；首报申告数按当时实际情况填写，不预设为 0 |
| **主备双断检测** | 多条海缆同时故障时，动态识别累积主备双断电路 |
| **故障历史** | 终报后保留完整事件和传报快照，海缆状态自动恢复正常，重启后继续保留 |

## 安装与启动

### 1. 放置数据文件

首次运行可使用项目内的初始槽路表，也可在网页中上传最新槽路表。系统只
读取大 Excel 文件中的 `金桥机房电路` 工作表，上传文件名不受限制。

```
SubSentry/
└── 上海ITMC电路槽路表0407改进版.xlsx
```

> 上传后的当前文件保存在 `data/uploads/`，数据变化后缓存会自动刷新。

### 2. 启动服务

```bash
cd SubSentry
python app.py
```

启动成功后显示：

```

  └─────────────────────────────────────────────────────┘

  启动地址: http://localhost:8080
  按 Ctrl+C 停止
```

### 3. 打开浏览器

访问 `http://localhost:8080`

## 使用说明

### 录入故障

1. 在左侧「故障录入」区域，从下拉菜单选择故障海缆段落
2. 选择中断时间（精确到分钟）
3. 点击「📡 生成通报」按钮

系统将自动判断登陆站和适用流程，更新态势图、分析业务影响，并生成当前阶段的传报文案。

### 按时间线传报

崇明出口的固定流程为：

```text
首报 → 业务影响情况传报 → 断点续报 → 维修计划续报 → 终报
```

南汇出口只显示业务影响情况传报。实际完成某个渠道后，点击该渠道左侧圆圈确认；生成或复制文案不会自动视为已经传报。

断点、维修计划和终报阶段只要求填写本阶段新增的信息。已经完成的阶段会锁定，业务影响完成时会保存分析快照，防止后续上传新槽路表改变历史内容。

### 下载附件

在“业务影响情况传报”的“邮件及附件”渠道旁点击「下载附件」，生成可直接发送的 Excel 文件。

文件名格式：`国际海缆故障影响业务统计表 {海缆名} {段落}（{路由}）.xlsx`

### 多条海缆故障

可连续录入多条海缆故障。系统会：
- 在态势图上同时标注所有中断段落
- 对新录入的故障进行全量重算，识别**主备双断**电路
- 在故障时间线中显示所有故障事件

### 终报和删除

终报的全部渠道确认完成后，系统保留该故障历史，并将海缆恢复为正常状态。只有确实不需要该记录时，才使用左侧的「删除」按钮。

## 业务影响分类说明

| 标注 | 含义 | 业务是否中断 |
|------|------|------------|
| **无保护** | 单腿电路，路由已断 | ✅ 中断 |
| **主备双断** | 所有路由均已断 | ✅ 中断 |
| **主用** | 第一路由断，但备用存活 | ❌ 通过备用在跑 |
| **备用** | 第一路由存活，某备用断 | ❌ 保护能力降低 |
> 微信通报中的「X 条专线中断」只统计**无保护 + 主备双断**的电路。
> IP 带宽损失同样只统计真正中断的 IP 电路。

## 数据文件说明

| 文件 | 说明 |
|------|------|
| 网页上传的槽路表 | **用户维护**，系统读取其中的 `金桥机房电路` 工作表，并保存在 `data/uploads/`。 |
| `data/fault_state.json` | **系统自动维护**，存储事件变量、渠道完成状态和业务影响快照。 |

## 项目结构

```
SubSentry/
├── app.py                  # Flask 主程序
├── cable_config.py         # 8 条海缆段落硬编码配置
├── circuit_analyzer.py     # 电路分析引擎（匹配 / 分类 / 统计）
├── fault_workflow.py       # 五阶段流程、变量和渠道完成状态
├── report_builder.py       # 各阶段邮件、短信和微信模板
├── excel_builder.py        # 统计表 xlsx 生成
├── supervisor_excel.py     # 专业主管分阶段 Excel 生成
├── data/
│   └── fault_state.json    # 故障状态持久化（自动创建）
├── templates/
│   └── index.html          # 单页前端
├── 金桥机房电路表.xlsx       # 数据文件（用户放置）
└── README.md
```
